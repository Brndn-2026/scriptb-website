About ScriptB

ScriptB is a simple scripting language built in Python. It aims to be readable, approachable, and easy to experiment with for beginners, hobbyists, and people who want lightweight scripting without a lot of ceremony.

The project is intentionally small. It favors direct commands and clear syntax over large framework complexity. That makes it useful for small automation tasks, learning core language ideas, and quickly testing script logic.

Design goals

  • Simple syntax for common tasks
  • Clear and understandable commands
  • Fast experimentation in a REPL
  • Support for small automation workflows
  • Friendly entry point for new programmers

Example

Current direction

ScriptB is still early-stage. The project is focused on improving the language itself, making documentation stronger, and creating more examples so people can understand how it fits into real work.
